Puntajes del simulacro

Valores generales del simulacro.

Distribuye las preguntas por curso

Abre un curso para editarlo. Las preguntas deben cubrir el cuadernillo completo, sin repetirse.

Áreas y cantidad evaluable

La cantidad evaluable puede ser diferente para cada área. Los códigos deben coincidir con los asignados a tus estudiantes.

Cada pregunta pertenece a un curso. Para cada área indica los números aplicables. Ejemplo: 1-10,15,18-20. En «Elegir cupo» el estudiante elige qué responder, hasta el límite definido.

Ajustes de puntaje para todos los cursos

Carga la clave de respuestas

Selecciona un curso y marca A, B, C, D o E para cada pregunta. El editor avanza solo y muestra las pendientes. Puedes guardar el borrador y continuar después.

Pegar una lista de claves (opcional)

Si ya tienes las respuestas, pega A B C D E… en orden, sin escribir números. Reemplaza la lista completa; revisa el contador y las preguntas en el editor visual. Para corregir preguntas sueltas también se admite una línea por pregunta, como 1,B.

B/D acepta ambas alternativas. Las anulaciones y puntajes por alternativa se configuran en las excepciones.

Excepciones de puntaje y versiones del cuadernillo

Una versión modifica el orden de las preguntas y conserva las alternativas. Deja vacío para usar A en el orden original.

Generar cartillas

El alumno escribe sus datos y marca su código de 8 dígitos y su área. Los QR vinculan las caras con el examen, sin contener nombres. Cada cartilla es única: genera la cantidad necesaria, no fotocopies una sola.

Calificación manual

Registra las respuestas del estudiante con el editor rápido: haz clic o pulsa A–E y avanzará a la siguiente pregunta. Puedes marcar varias alternativas o registrar una pregunta en blanco.

Pegar respuestas manualmente (opcional)

Admite una lista como A B C D o una respuesta por línea (1,A). Usa - para indicar una pregunta en blanco.

Corregir una calificación anterior
Escanea y revisa antes de guardar notas. Usa el cristal para cartillas de un cuarto de hoja; para media hoja o A4 puedes usar el alimentador. Incluye ambas caras de cada cartilla de cuarto en el mismo lote.

Escanear con NAPS2

NAPS2 y el controlador Brother deben estar instalados en la computadora donde se ejecuta INGEMAT. Puedes continuar añadiendo hojas al terminar cada captura.

Brother MFC-T920DW: alimentador de hasta 20 hojas, sin escaneo dúplex automático. El cuarto recortado es demasiado pequeño para su alimentador. Se usa 300 ppp en escala de grises.

Proveedor y mensajes

Conexión con Baileys, sin credenciales de una API de pago. Guarda los mensajes, vincula el teléfono y después activa los avisos.

Baileys se ejecuta sin navegador en la PC del servidor. Es una biblioteca no oficial que puede necesitar actualizaciones; sus fallos se aíslan del sistema académico.

Variables: {nombre}, {fecha}, {hora}, {estado}. Separa varias versiones con una línea ---. El sistema elige una por cada aviso registrado.

Variables: {nombre}, {examen}, {puntaje}, {area}. Conserva {nombre} para identificar al estudiante.

Vincular WhatsApp

Pulsa Conectar para vincular el teléfono de la academia.

WhatsApp del teléfono → Dispositivos vinculados → Vincular un dispositivo. El QR caduca y se renueva automáticamente.

Primero vincula el teléfono; después activa los avisos. Detener la conexión desactiva los envíos y conserva la sesión. Volver a vincular elimina solo la sesión local de WhatsApp.

Las asistencias y calificaciones se guardan aunque WhatsApp falle. Los avisos quedan en cola; una entrega incierta requiere revisión antes de reenviar.

Si falla el componente, revisa el paquete Baileys y su versión. Diagnóstico en la PC del servidor: npm run whatsapp:doctor.
